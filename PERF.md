# Performance ledger

Kept and skipped ideas, with the measurement behind each. Read this before you propose a new experiment.

Method for the DB numbers: temporary tables on the dev Postgres, `ANALYZE` run, same query before and after, median of 10–15 runs. They measure the query shape, not a full chat turn.
